# AI Network Anomaly Detection

AI-based system that detects unusual network traffic behavior using machine learning.

## Project Description

This project analyzes network traffic and detects anomalies that may indicate cyber attacks or suspicious behavior.
It uses machine learning models to classify normal and abnormal traffic patterns.

The tool can be useful for:

* Network monitoring
* Intrusion detection
* Cybersecurity research
* Learning network traffic analysis

---

## Features

* Packet capture using Scapy
* Traffic feature extraction
* Machine learning anomaly detection
* Real-time monitoring
* Simple dashboard output

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/ai-network-anomaly-detection.git
cd ai-network-anomaly-detection
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the program

```bash
python main.py
```
